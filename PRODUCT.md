# HeyBuddy
<!-- impeccable:product-schema 1 -->

## Platform
Windows native desktop (WPF). The skill's web/iOS/Android schema does not describe this platform; native Windows conventions govern.

## Stack
C#/.NET 10 WPF, SQLite, native Windows APIs, llama.cpp, Whisper.net, Piper, official MCP C# SDK. Explicitly approved in the implementation request.

## Users
Windows users who want a private desktop assistant for work, learning, dictation, documents, development, and connected services.

## Product Purpose
An inspectable, local-first desktop companion reproducing the useful personal features of HeyClicky 1.0.48. Press a shortcut, speak or type, understand the screen, get visual guidance, or delegate an approved task.

## Capabilities and Constraints
Local AI is the default; cloud providers are optional and explicit. English UI; English, Persian and Turkish speech. All useful Windows-compatible connectors, separately configured and tested. No subscription to this app. Third-party account requirements remain visible. Screen guidance never injects input. Sensitive business actions require a concrete preview and approval. Preserve data over restart and upgrades.

## Evidence on Hand
HeyClicky 1.0.48 build 57 DMG, inspected read-only; public changelog and original MIT repository. Native Mac behavior and cloud intelligence are references, not working Windows components. The validation PC has an i7-12700K, 32 GB RAM, and an RTX 3070 Ti with 8 GB VRAM.

## Brand Commitments
Cursor companion, playful blue pointer character, compact floating controls and approachable plain language, closely following the user's Clicky reference.

## Accessibility & Inclusion
Keyboard operation, reduced motion, readable contrast, mixed-DPI displays, Persian right-to-left content, no forced cloud use.
