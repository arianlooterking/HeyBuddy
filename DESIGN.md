# HeyBuddy desktop

## Direction
Operate mode. Friendly blue cursor character and warm ivory workspace. Segoe UI Variable typography; deep ink text, cobalt primary actions, restrained amber errors. A compact floating companion is the everyday entry; a resizable command-center window contains conversation, tasks, connections, knowledge, models and settings.

## Surface rules
Use a 208px sidebar, spacious conversation pane, bottom composer, and contextual secondary details. Group settings in flat labeled sections rather than nested cards. Rounded 10px controls, 16px panels, one light border, and modest shadows on floating windows. Buttons have explicit hover/disabled/focus states. Font sizes 14 body, 12 supporting, 24 page heading. The native system font is intentional for a Windows operating tool.

## Behavior
Only capture while explicitly requested. Show listening/thinking/speaking states and active model. Stop stays available. Provider and connection failures name a recovery action. Persian message content uses RTL independently of the English shell. Preserve cursor/keyboard focus during overlays and dictation.

## Build authority
Approved implementation plan and Clicky reference govern. Build directly in WPF; image-led website composition is not applicable to the native desktop controls. Canvas UI is being evaluated as a supplementary reusable design reference.
