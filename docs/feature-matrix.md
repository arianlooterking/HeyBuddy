# HeyBuddy feature matrix

Reference: supplied HeyClicky 1.0.48, build 57; inspected September 3, 2026. The Mac installer is a behavioral inventory, not executable Windows code. [Original MIT reference](https://github.com/farzaa/clicky) and [public changelog](https://www.heyclicky.com/changelog) describe different generations; private/cloud behavior cannot be inferred from the older source alone.

The current release is 0.3.0. Talk-time focused-app vision, typed screen intent, accessibility-aligned pointers, click-progressed guidance, and accessibility-first button control are covered by local model, parser, settings, render, and owned-window fixtures. The compact input-reactive companion has 16 rendering checks. A separate eight-second probe reached local recognition through the selected USB microphone, though broad intelligibility testing remains open. Authenticated account connectors, a live physical standalone-modifier shortcut, and the broader cross-application matrix remain open; historical or fixture tests are not presented as evidence for those flows.

Native iMessage, Find My and macOS automation are unsupported on Windows. Browser links are clearly labeled as browser access. This matrix describes functional coverage and limits; it is not a full-parity certification.
